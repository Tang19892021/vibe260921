## 1. 배경 및 목적

허태영은 **바이브코딩(AI와 함께 코딩), Python, HTML5**를 주력으로 하는 개발자다. 지금까지 만든 결과물(뱀 게임, 테트리스 등)을 한곳에서 보여 주고, 처음 방문한 사람이 **"이 사람이 무엇을 만들 수 있는가"를 1분 안에 파악**하게 하는 개인 프로필 웹사이트가 필요하다.

### 목표
1. 방문자가 첫 화면에서 이름, 전문 분야, 연락 방법을 즉시 알 수 있다.
2. 만든 프로젝트를 **설명만 읽는 것이 아니라 직접 실행해 볼 수 있다** (HTML5 게임은 사이트 안에서 바로 플레이).
3. 채용 담당자, 협업 제안자, 외주 의뢰자가 **한 번의 클릭으로 연락**할 수 있다.
4. 새 프로젝트를 추가할 때 **HTML 한 블록(또는 데이터 한 줄)만 추가**하면 되는 유지보수 쉬운 구조로 만든다.

### 비목표 (이번 범위 아님)
- 블로그, 댓글, 로그인/회원 기능
- 서버, 데이터베이스, 관리자 페이지
- 다국어 자동 번역 (한국어 우선, 영어는 2차 검토)

## 7. 기술 스택

| 영역 | 선택 | 이유 |
|---|---|---|
| 마크업 | HTML5 (시맨틱 태그) | 주력 분야이며 SEO·접근성에 유리 |
| 스타일 | CSS3 (변수, Grid/Flexbox, 미디어 쿼리) | 프레임워크 없이 가볍게 |
| 동작 | Vanilla JavaScript (ES6+) | 의존성 0, 학습 및 시연에 적합 |
| 호스팅 | GitHub Pages 또는 Netlify (무료 정적 호스팅) | 배포가 간단 |
| 개발 방식 | 바이브코딩 (Claude Code) | 본인의 주력 방식을 사이트 제작 과정에서도 그대로 보여 줌 |

## 8. 디자인 방향

- **분위기:** 깔끔한 다크 기반, 포인트 컬러 1개(예: 블루), 개발자다운 모노스페이스 포인트 폰트
- **타이포:** 본문은 시스템 한글 폰트(Pretendard 또는 Malgun Gothic 대체), 제목과 코드 느낌 문구에만 모노스페이스
- **핵심 인상:** 텍스트 소개보다 **살아 움직이는 결과물**이 먼저 보이는 구성 (Hero 배경에 미니 테트리스 블록 애니메이션 등)
- **모션:** 짧고 절제된 전환 (200~400ms). 과한 효과는 지양
- 참고: 디자인 시안이 없으므로, 구현 단계에서 컬러와 레이아웃 후보를 먼저 보여 주고 확정한다
